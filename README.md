# 🏔️ Prototipo Web – Agencia de Turismo en Chile

Prototipo de sitio web para una agencia de turismo ficticia, creado como **propuesta comercial** para potenciales clientes del rubro turístico. Transmite la experiencia de viajar por Chile mediante fotografías de paisajes, tarjetas visuales y una navegación clara.

## ✨ Características

- Diseño visual orientado al turismo y la aventura, con jerarquía visual clara.
- Carrusel interactivo de destinos destacados.
- Catálogo de tours mediante tarjetas descriptivas.
- Formulario de contacto con selección de tour de interés.
- Navegación por header y footer, más un botón flotante para volver al inicio.

## 🧭 Secciones del sitio

| Sección | Descripción |
|---|---|
| **Hero principal** | Bienvenida con fotografías de paisajes de Chile. |
| **¿Por qué elegirnos?** | Atributos, beneficios y propuesta de valor de la agencia. |
| **Destinos destacados** | Tarjetas visuales en un carrusel interactivo. |
| **Diferenciación** | Qué distingue a la agencia de otras alternativas. |
| **Tours disponibles** | Catálogo de experiencias con sus principales características. |
| **Sobre nosotros** | Identidad, propósito y propuesta de la agencia. |
| **Opiniones** | Testimonios y experiencias de clientes. |
| **Contacto** | Formulario para elegir un tour, dejar datos y enviar un mensaje. Informa al usuario que será contactado posteriormente. |
| **Header y footer** | Navegación a todas las secciones de la página. |
| **Botón flotante** | Retorno rápido al inicio. |

## 🛠️ Tecnologías

- **HTML5:** estructura y contenido semántico.
- **CSS3 / SCSS:** estilos, variables, anidación y organización modular.
- **JavaScript:** carruseles, navegación y flujo del formulario.
- **CDN:** bibliotecas y recursos externos.
- **Unsplash:** fotografías de destinos y experiencias.

## ⚠️ Alcance y limitaciones

- **Solo escritorio:** el prototipo está pensado para pantalla completa en computadores. **No es responsive** (móviles y tablets).
- **Formulario de demostración:** no está conectado a un backend ni a un sistema de reservas, por lo que **las solicitudes no se almacenan ni se envían**.
